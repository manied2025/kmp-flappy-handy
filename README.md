# KMP Flappy Handy

Ein einfaches Touch-basiertes Jump-'n'-Run-Spiel im Stil von Flappy Bird.  
Die Spielfigur ist ein Handy mit Gesicht.  
Erstellt von Handy Doc NW – [www.handy-doc-nw.de](https://www.handy-doc-nw.de)

## Spielen

Einfach auf den Bildschirm tippen oder klicken, um das Handy zu steuern.  
Weiche den Röhren aus und sammle Punkte!
